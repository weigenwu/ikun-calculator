Fast Read 102 细胞计数板计算器

20 µL 直接计数版：不加台盼蓝，不额外稀释，输入一个大方格内数到的细胞数量。

20 µL 只是上样体积记录，不参与浓度公式。
如果数多个大方格，请输入平均值。
例如离心重悬后这一管目前有 1 mL。
默认 1.5 × 10^6 cells/mL。
计算说明与提醒
公式
当前浓度 = 一个大方格细胞数量 × 10^4
当前总细胞数 = 当前浓度 × 当前细胞悬液体积
目标最终体积 = 当前总细胞数 / 目标细胞浓度
需要补加培养基 = 目标最终体积 - 当前细胞悬液体积
提醒
如果以后改成细胞液和台盼蓝 1:1 混合计数，当前浓度需要乘以 2。
边界细胞建议固定计入两条边，例如左边和上边计入，右边和下边不计入。

qPCR RT 逆转录与上机配液计算器

同一份 RNA 样本列表用于 RT 体积计算和 qPCR 样本数统计。

复孔数和额外多配孔数都可以按当天实验调整。

一、RT 逆转录体系

每行一个样本。格式：样本名, RNA浓度。浓度单位默认为 ng/µL。
默认 1000 ng，可改为 800、500 等。

二、qPCR 上机体系

每行一个基因。程序按“样本 × 基因 × 复孔数”计算。
计算说明
RT 逆转录
RNA体积 = 自定义逆转录RNA量 / RNA浓度
无酶水体积 = RT总体系 - RNA体积 - 5×gDNA体积 - 4×逆转录试剂体积 - 其他固定组分体积
qPCR
每孔无酶水 = 每孔总体系 - qPCR Mix - Forward primer - Reverse primer - cDNA - 其他固定组分
每组实际配液孔数 = 复孔数 + 额外多配孔数
实际上板孔数 = 样本数 × 基因数 × 复孔数
实际配液总孔数 = 样本数 × 基因数 × 每组实际配液孔数

qPCR 下机数据分析计算器

导入 QuantStudio 下机文件或粘贴结果表，自动计算 Ct 均值、ΔCt、ΔΔCt、2^-ΔΔCt、P 值，并生成柱状图与 Prism CSV。

默认逻辑：目标基因 GeneA，内参 ACTB，对照样本 Control。

一、导入下机数据

优先读取 QuantStudio 导出的 .xlsx 中的“结果分析”表。也可以直接粘贴 Excel 表格内容。
尚未读取文件。
至少需要列：样本名、基因名称、Ct/Cт。可包含反应孔位置、Cт SD、扩增状态、Tm1 等列用于 QC。

二、分析设置

多个目标基因可用逗号分隔，例如 GeneA,GeneB。
导入或粘贴数据后，会自动从“样本名”列生成可选样本。
当选择“自定义比较方案”时生效。适合一批数据中分开做 Control_A vs Treat_A、Control_B vs Treat_B1/Treat_B2 等不同比较。
基于每个技术孔计算出的 2^-ΔΔCt 做组间检验。

相对表达量柱状图

计算说明
核心公式
Ct均值 = 同一样本同一基因所有有效复孔 Ct 的平均值
ΔCt = Ct(目标基因) - Ct(内参基因)
ΔΔCt = ΔCt(样本) - 平均ΔCt(对照样本)
相对表达量 = 2^(-ΔΔCt)
统计与导出
网页会对每个样本的技术孔相对表达量计算 mean、SD、SEM，并把每个重复孔作为 Prism CSV 的子列导出。
技术重复 t-test 只能反映当前孔级数据差异；正式论文统计通常建议使用独立生物学重复。

BCA 蛋白浓度与 WB 已煮样上样量计算器

适用于先加 5× loading buffer 煮样，BCA 出结果后再从已煮样取样并用 1× loading buffer 补足的流程。

上胶当天只计算“已煮样 + 1× loading buffer”，不再计算加入 5× loading buffer 的体积。

一、BCA 标准曲线与 OD

默认标准曲线：y = 2.0352x - 0.4435。
可输入 1 个或多个，用逗号、空格或制表符分隔。
每行一个样本。格式：样本名, 稀释倍数, OD1, OD2, OD3。OD 复孔可以是 2 个、3 个或更多。

二、已煮样 WB 上样设置

5× loading buffer 按蛋白原液:loading buffer = 4:1 混合时填 5。
留空时按最稀已煮样计算所有样本都能达到的最大统一蛋白量。
计算说明
BCA 浓度计算
平均样本OD = 样本复孔OD平均值
平均空孔OD = 空孔OD平均值
校正OD = 平均样本OD - 平均空孔OD
稀释后浓度 = (校正OD - intercept) / slope
原液蛋白浓度 = 稀释后浓度 × 稀释倍数
已煮样 WB 上样量
蛋白原液占比 = (loading buffer倍数 - 1) / loading buffer倍数
已煮样蛋白浓度 = 原液蛋白浓度 × 蛋白原液占比
自动统一蛋白量 = min(已煮样蛋白浓度 × 每泳道最终上样体积)
取已煮样体积 = 统一蛋白量 / 已煮样蛋白浓度
1× loading补足体积 = 每泳道最终上样体积 - 取已煮样体积

三、PEI 与 Opti-MEM 设置

默认按总质粒量的 3 倍体积理解，即 3 µL PEI / 1 µg DNA。
这里按 5 µg 总质粒对应 400 µL Opti-MEM 线性换算。
计算说明
三质粒质量分配
比例总和 = 目的质粒比例 + psPAX2比例 + pMD2.G比例
单个质粒质量 = 总质粒量 × 该质粒比例 / 比例总和
单个质粒体积 = 单个质粒质量 × 1000 / 质粒浓度
PEI 与 Opti-MEM
PEI体积 = 总质粒量 × PEI体积系数
Opti-MEM总量 = 总质粒量 / 参考DNA量 × 参考Opti-MEM体积
Opti-MEM补足量 = Opti-MEM总量 - 总质粒体积 - PEI体积
