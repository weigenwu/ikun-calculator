Fast Read 102 细胞计数板计算器

20 µL 直接计数版：不加台盼蓝，不额外稀释，输入一个大方格内数到的细胞数量。

20 µL 只是上样体积记录，不参与浓度公式。
如果数多个大方格，请输入平均值。
例如离心重悬后这一管目前有 1 mL。
默认 1.5 × 10^6 cells/mL。
计算说明与提醒
公式
当前浓度 = 一个大方格细胞数量 × 10^4
当前总细胞数 = 当前浓度 × 当前细胞悬液体积
目标最终体积 = 当前总细胞数 / 目标细胞浓度
需要补加培养基 = 目标最终体积 - 当前细胞悬液体积
提醒
如果以后改成细胞液和台盼蓝 1:1 混合计数，当前浓度需要乘以 2。
边界细胞建议固定计入两条边，例如左边和上边计入，右边和下边不计入。

细胞铺板计算器

按当前细胞浓度、目标每孔细胞数和孔数，计算每孔及总量需要加入的细胞悬液和培养基。

适合 6/12/24/48/96 孔板铺板前快速配悬液。
可直接填上一个计数模块算出的浓度。
推荐 5% 到 15%，避免移液损耗。
计算说明
每孔细胞悬液体积 = 目标每孔细胞数 / 当前细胞浓度
每孔培养基体积 = 每孔终体积 - 每孔细胞悬液体积
总量 = 每孔体积 × 孔数 × (1 + 多配比例)

药物梯度处理计算器

输入药物母液浓度和目标处理浓度列表，自动计算每个浓度需要的母液、培养基和溶剂比例。

默认母液单位 mM，处理终浓度单位 µM。
可用逗号、空格或换行分隔。0 会作为 vehicle/control 组。
低于该体积时提示先配中间液。
计算说明
母液体积 = 目标终浓度 / 母液浓度 × 终体积
培养基体积 = 终体积 - 母液体积
溶剂比例 = 母液体积 / 终体积 × 100%
如果不同浓度组需要严格保持一致 DMSO/溶剂比例，建议用最高浓度组的溶剂比例给低浓度组补 vehicle。

CCK8 / MTT / ADCC 细胞活性分析计算器

粘贴 OD、吸光度或发光读数，自动扣空白、归一化、计算存活率/抑制率/ADCC杀伤率，也可绘制 OD450 时间曲线并导出 Prism CSV。

CCK8/MTT 看活性，ADCC 看杀伤；数据结构类似，公式不同。

一、读数与方法

终点模式：组名, 复孔1, 复孔2。时间曲线：面板名, 组名, 时间h, 复孔1, 复孔2。可从 Excel 粘贴，逗号或制表符都可以。
时间曲线里不同面板可用逗号分隔多个对照名，例如 Control, Vector。

二、图片 / 读板助手

上传照片后在这里预览。若浏览器支持本地文字识别，可尝试自动读取数字。
网页会优先识别 A-H 行和 12 列小数；如果只有连续 96 个小数，也会按 A1-H12 自动铺板。
提示：纯本地网页无法保证所有照片都能 OCR 成功，建议优先使用仪器导出的报告或手机系统 OCR 文本；孔位选择和后续计算会在本地完成。
当前未选择孔位
点击孔位选择；按住 Ctrl/⌘ 可多选复孔，然后一次性标记为空白、对照、实验组、样本或标准品。
计算说明
CCK8 / MTT
校正读数 = 原始读数 - 空白均值
存活率% = 校正读数 / 对照组校正均值 × 100
抑制率% = 100 - 存活率%
CCK8 / MTT 时间曲线
每个时间点按复孔计算均值、SD、SEM；若同一面板和时间含 Blank 组，会先扣除该时间点空白均值。
ADCC 存活读数法
杀伤率% = [1 - (实验孔 - 空白 - Effector only背景) / (Target only - 空白)] × 100
ADCC / LDH 释放法
杀伤率% = (实验释放 - Effector背景 - Target自发释放) / (Target最大裂解 - Target自发释放) × 100
不同试剂盒公式可能略有差异；这里是常用数据处理框架，正式记录请按你实际试剂盒说明书核对。

qPCR RT 逆转录与上机配液计算器

同一份 RNA 样本列表用于 RT 体积计算和 qPCR 样本数统计。

复孔数和额外多配孔数都可以按当天实验调整。

一、RT 逆转录体系

每行一个样本。格式：样本名, RNA浓度。浓度单位默认为 ng/µL。
默认 1000 ng，可改为 800、500 等。

二、qPCR 上机体系

每行一个基因。程序按“样本 × 基因 × 复孔数”计算。
计算说明
RT 逆转录
RNA体积 = 自定义逆转录RNA量 / RNA浓度
无酶水体积 = RT总体系 - RNA体积 - 5×gDNA体积 - 4×逆转录试剂体积 - 其他固定组分体积
qPCR
每孔无酶水 = 每孔总体系 - qPCR Mix - Forward primer - Reverse primer - cDNA - 其他固定组分
每组实际配液孔数 = 复孔数 + 额外多配孔数
实际上板孔数 = 样本数 × 基因数 × 复孔数
实际配液总孔数 = 样本数 × 基因数 × 每组实际配液孔数

PCR / qPCR Master Mix 计算器增强版

按样本、目标引物、复孔数和多配比例，自动计算单孔体系、总量、按目标或按样本分组的 Master Mix。

适合常规 PCR、qPCR 上机前快速配液。

一、样本与目标

每行或逗号分隔一个样本名。
每行或逗号分隔一个目标。qPCR 可填基因名，PCR 可填引物对名称。

二、反应体系

2× Mix 填 2；4× Mix 填 4。Mix 体积自动按总体系 / 倍数计算。
计算说明
Master Mix 每孔体积 = 总体系 / Master Mix 倍数
Primer 每孔体积 = 目标终浓度 × 总体系 / stock 浓度
水 = 总体系 - Mix - F primer - R primer - 模板 - 其他固定组分
配液反应数 = ceil(实际反应数 × (1 + 多配比例)) + 至少额外反应数
选择“模板单独加”时，网页按每个目标引物对配公共 Master Mix；选择“模板混入”时，网页按每个样本 × 目标单独配完整体系。

BCA 蛋白浓度与 WB 已煮样上样量计算器

适用于先加 5× loading buffer 煮样，BCA 出结果后再从已煮样取样并用 1× loading buffer 补足的流程。

上胶当天只计算“已煮样 + 1× loading buffer”，不再计算加入 5× loading buffer 的体积。
可在“活性/ADCC”的图片 / 读板助手里上传或解析 96 孔板读数，标记空白、标准品和样本后，一键生成到这里并拟合标准曲线。

一、BCA 标准曲线与 OD

默认标准曲线：y = 2.0352x - 0.4435。
可输入 1 个或多个，用逗号、空格或制表符分隔。
每行一个样本。格式：样本名, 稀释倍数, OD1, OD2, OD3。OD 复孔可以是 2 个、3 个或更多。

二、已煮样 WB 上样设置

5× loading buffer 按蛋白原液:loading buffer = 4:1 混合时填 5。
留空时按最稀已煮样计算所有样本都能达到的最大统一蛋白量。
计算说明
BCA 浓度计算
平均样本OD = 样本复孔OD平均值
平均空孔OD = 空孔OD平均值
校正OD = 平均样本OD - 平均空孔OD
稀释后浓度 = (校正OD - intercept) / slope
原液蛋白浓度 = 稀释后浓度 × 稀释倍数
已煮样 WB 上样量
蛋白原液占比 = (loading buffer倍数 - 1) / loading buffer倍数
已煮样蛋白浓度 = 原液蛋白浓度 × 蛋白原液占比
自动统一蛋白量 = min(已煮样蛋白浓度 × 每泳道最终上样体积)
取已煮样体积 = 统一蛋白量 / 已煮样蛋白浓度
1× loading补足体积 = 每泳道最终上样体积 - 取已煮样体积

计算说明

PEI体积 = 总质粒量 × PEI体积系数
Opti-MEM总量 = 总质粒量 / 参考DNA量 × 参考Opti-MEM体积
Opti-MEM补足量 = Opti-MEM总量 - 总质粒体积 - PEI体积
